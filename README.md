# 🚖 CLIXAT - Sistema de Cadastro e Gestão de Clientes de Táxi

![CLIXAT Banner](https://raw.githubusercontent.com/Mattheus-gs/CLIXAT/main/foto1.png)

O **CLIXAT** é uma plataforma web desenvolvida para taxistas que buscam modernizar e agilizar a gestão de sua carteira de clientes. O sistema permite cadastrar passageiros frequentes, registrar detalhes sobre as corridas rotineiras e, com apenas um clique, gerar um **auto-texto formatado** com a lista de clientes pronto para ser copiado e compartilhado (via WhatsApp, SMS ou blocos de notas).

---

## 🚀 Funcionalidades Principais

*   **Cadastro de Clientes Personalizado:** Registro completo focado nas necessidades do taxista.
*   **Gerador de Auto-Texto:** Compila todos os clientes cadastrados em uma lista organizada em texto.
*   **Cópia Rápida para Área de Transferência:** Botão dedicado para copiar o texto formatado instantaneamente.
*   **Interface Otimizada:** Design limpo, focado na usabilidade rápida do dia a dia nas ruas.

---

## 📋 Informações Armazenadas por Cliente

Para garantir um serviço de táxi eficiente, cada cadastro conta com os seguintes campos:

| Campo | Descrição |
| :--- | :--- |
| **Nome do Cliente** | Identificação do passageiro. |
| **Valor** | Preço combinado ou estimado da corrida recorrente. |
| **Distância** | Quilometragem estimada do trajeto. |
| **Ponto Inicial** | Local de partida ou endereço de busca. |
| **Dias da Semana** | Dias em que o cliente costuma solicitar a corrida (ex: Seg, Qua, Sex). |
